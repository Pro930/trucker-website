# TruckPro - Professional Trucking Website

A modern, responsive website for TruckPro trucking services.

## Features

✅ **Responsive Design** - Works on desktop, tablet, and mobile devices
✅ **Service Showcase** - Display trucking services (FTL, LTL, Refrigerated, etc.)
✅ **Fleet Information** - Highlight available trucks and equipment
✅ **About Section** - Company story and statistics
✅ **Contact Form** - Easy customer inquiry submission
✅ **Smooth Animations** - Modern scroll effects and transitions
✅ **24/7 Operations** - Professional branding for trucking industry

## File Structure

```
trucker-website/
├── index.html      # Main HTML file with all sections
├── styles.css      # Complete styling and responsive design
├── script.js       # Interactive features and animations
└── README.md       # This file
```

## Sections

1. **Navigation Bar** - Sticky navigation with smooth scrolling
2. **Hero Section** - Eye-catching headline and call-to-action
3. **Services** - Four main service offerings
4. **Fleet** - Display of available vehicles
5. **About** - Company information and key statistics
6. **Contact** - Contact information and inquiry form
7. **Footer** - Links and copyright information

## Technologies Used

- HTML5
- CSS3 (with Grid and Flexbox)
- Vanilla JavaScript
- Responsive design (mobile-first approach)

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customize the content, colors, and information to match your company

## Customization

### Colors
Main colors are defined in `styles.css`:
- Primary Blue: `#1e3c72`
- Secondary Blue: `#2a5298`
- Accent Purple: `#667eea`
- Highlight Red: `#ff6b6b`

### Content
Edit `index.html` to update:
- Company name and contact information
- Service descriptions
- Fleet details
- About section content
- Social media links

### Styling
Modify `styles.css` to:
- Change colors and fonts
- Adjust spacing and sizing
- Add new sections
- Customize animations

## Deployment

### GitHub Pages
1. Go to repository settings
2. Scroll to "GitHub Pages"
3. Select "main" branch as source
4. Your site will be live at `https://yourusername.github.io/trucker-website`

### Other Hosting
- Simply upload the files to your web hosting service
- No build process or dependencies required
